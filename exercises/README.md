# Datahandling course: Exercises

## File structure

 - For each exercise session there is one folder `01_*`, `02_*`, etc.
 - Within these folders there at least the following four subfolders:
    - `exercises`: the actual exercises of the respective session handed out two weeks before the respective session. Typically the exercise sheet consists of 1-4 practical coding exercises as well as three mock exam questions. Both parts of the exercise sheet correspond to the topics of the previous two lectures.
    - `solutions`: the solutions to the exercises. In the case of coding exercise, these are rather brief sample solutions (the details are step-by-step discussed during the exercise session) as well as the solutions to the respective mock exam questions. These will be *published in Canvas* (only accessible to course participants).
    - `notes`: similar to lecture notes, these cover additional material discussed during the exercise sessions. These will be *published in the open web* (accessible to anybody) after the exercise session. 
    - `slides`: slides used during the exercise session (to support the step-by-step explanation of the solutions). For some sessions there are currently no slides. There is not necessarily a need for slides depending on the topic (the notes and solutions are more relevant). 
    - In addition, there is the material used as input (typically data-files) for the hands-on exercises as well as the output and additional code to demonstrate the solution during the session. For example in `01_tools_textfiles` is a folder `r_course` which is the result of exercise A of the corresponding exercises.
 - `advanced`: code, data, materials/ideas for advanced exercises
 - `img`: images used in the exercise materials
 - `style`: css stylesheets used for the materials
 - `references`: bibtex references used in the materials
